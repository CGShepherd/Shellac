# SR-040 — Mechanical Datum, Full-BOM Census and Critical Placement Closure — Rev A0

## Disposition

SR-040 closes the former audio-enclosure datum blocker using the authoritative
METCASE M5502119 Issue-1 manufacturer drawing.

The audio PCB is frozen at **220 x 140 mm** on a removable **231 x 219 x 2 mm**
carrier plate. The PCB lower-left origin is **(5.5, 39.5) mm** from the carrier
lower-left datum. Four non-plated M3-class PCB mounting holes are frozen at
8 mm board-edge inset with 8 mm copper keep-out diameters.

This is a mechanical datum freeze, not a claim that every critical component
coordinate is accepted.

## Authoritative evidence

METCASE M5502119 / UNICASE 2:
- overall envelope 260 x 250 x 90 mm;
- manufacturer base PCB width 241 mm;
- inside-face depth 229 mm;
- internal cover height 86.2 mm;
- removable top, base and front/rear panels.

Source:
`https://www.metcase.co.uk/en/Unicase/M5502119/M5502119.pdf`

## BOM closure

SR-040 adds a generated census of **every schematic component** and its:
- reference;
- sheet;
- electrical value / device identity;
- assigned footprint;
- PCB/panel ownership;
- procurement-resolution state.

This deliberately distinguishes:
1. **design freeze** — electrical value and footprint fixed;
2. **procurement freeze** — exact manufacturer series/MPN fixed.

Generic resistors/capacitors do not block critical placement or routing merely
because the manufacturer MPN is still open, provided value, tolerance,
technology and footprint requirements are already controlled.

## Routing release

Mechanical datums are now frozen. The remaining routing gate is human acceptance
of the manual-authority analogue clusters generated by the existing placement
model, especially SCH101, SCH103, SCH107 and SCH108.

After that acceptance, routing should start immediately.
