# Project Shellac — SR-006 SCH101 DIP-Switch Symbol Closure

**Revision:** A  
**Status:** SCH101 CAD-ready  
**Date:** 14 July 2026

SCH101 already emitted substantive signal wiring. Its sole readiness blocker
was the missing embedded definition for `ProjectShellac:DIP_Switch_Block`.

The writer now embeds a physical 16-pin representation of the eight-way SPST
DIP switch used by the approved internal gain selector.

The symbol is a configuration-control representation; the approved 14/18/22 dB
gain architecture is unchanged.
