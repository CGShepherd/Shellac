# Shellac Foundry

Foundry is the controlled engineering-governance layer for Project Shellac.

It does not replace the product design documents. It defines how evidence,
decisions, conflicts, risks and releases are handled so future engineering can
continue without relying on conversation history.

Start with:
- `FOUNDRY_BASELINE.md`
- `../config/foundry/foundry.yaml`
- `../docs/knowledge/DESIGN_TENETS.md`
- `../docs/knowledge/DESIGN_RULES.md`
- `../docs/knowledge/DECISION_REGISTER.md`
- `../docs/knowledge/RISK_REGISTER.md`

Foundry baseline: **FDR-001 / G3-025**.
